## 🌟 What is Advent of Code?
[Advent of Code](https://adventofcode.com/) is an annual December event created by **Eric Wastl**. It consists of an Advent calendar of small programming puzzles that can be solved in any language. 

### **How it Works:**
* **The Calendar:** One puzzle is released every day from December 1st to the 25th.
* **The Structure:** Each puzzle has two parts. You must solve Part 1 to unlock the coordinates or logic needed for Part 2.
* **The Goal:** Collect **50 stars** by the end of the month to "save Christmas."
